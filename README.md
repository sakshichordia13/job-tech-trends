# job-tech-trends
## Backend (Node + SQLite)
1. `cd server`
2. `npm install`
3. `npm run dev` (or `npm start` for production)

## Chrome Extension (MV3)
1. Open Chrome and go to `chrome://extensions`.
2. Enable "Developer mode".
3. Click "Load unpacked" and select the `extension` folder in this repo.

## Trending View
1. Ensure the backend is running at `http://localhost:3001`.
2. Open a job post, click "Analyze this job" to ingest data.
3. Click the "Trending" button in the popup to see top technologies.
